# Typography, Style and Brand Kit Integration

This reference specifies the visual, typographic, and color principles for PDF reports generated by `report-pdf`.

---

## 1. Typography Choices: Space Grotesk vs Montserrat

The document uses high-readability Google Fonts optimized for both desktop screen preview and high-resolution A4 print:

| Font | Characteristics | Recommended Role |
|---|---|---|
| **Space Grotesk** | Geometric, proportional, tech-inspired, bold modern lines. | **Headings (H1, H2, Cover Title)**, chapter numbers, milestone badges, callout headers. Ideal for technical, engineering, and developer-focused products. |
| **Montserrat** | Classic geometric sans-serif, clean, highly readable, versatile weight range (300–700). | **Body copy**, descriptive paragraphs, tables, subheadings, and captions. Guarantees long-form reading comfort on text-dense pages. |
| **Inter** *(Alternative)* | Neutral, crystal-clear, optimized for software interfaces and dense technical metrics. | Clean alternative for analytical or numerical reports. |

### Default Pairing Rule:
- **Headings**: `Space Grotesk` (Weight: 600–700)
- **Body Text**: `Montserrat` (Weight: 400 normal, 500 semibold, 700 bold)

---

## 2. Typographic Emphasis: Bold and Italics

The goal is to enable **fast visual skimming**:

- **Bold (`strong`, `b`)**:
  - Highlights keywords, metrics (e.g. **+45% speed**, **100% tests passing**), core technologies, and essential concepts.
  - Highlight concise information units, not entire sentences.
- *Italics (`em`, `i`)*:
  - Used for quotations, team rationale ("*why robustness was favored over immediate shortcuts*"), and side notes.
- `Badges & Pills`:
  - Used for statuses (e.g. `COMPLETED`, `IN PROGRESS`), versions (`v0.2.0`), and category tags.

## 3. Brand Kit Integration (`brand/brand-kit.json`)

If the repository contains `brand/brand-kit.json`, the skill automatically extracts:

```json
{
  "name": "Brand or Project Name",
  "tagline": "Project tagline or slogan",
  "colors": {
    "primary": "#2563EB",
    "secondary": "#0F172A",
    "accent": "#FACC15",
    "text": "#1E293B",
    "background": "#FFFFFF"
  },
  "fonts": {
    "title": { "family": "Space Grotesk" },
    "body": { "family": "Montserrat" }
  },
  "logo": {
    "file": "brand/logo.svg"
  }
}
```

### CSS Variables Mapping in Template:
- `--primary-color`: Main brand color (decorative rules, chapter numbers, heading accents).
- `--secondary-color`: Dark heading text, table header background.
- `--accent-color`: Badges, callout borders, quotes.
- `--text-color`: Primary body text (WCAG AAA contrast on white background).
- `{{LOGO_HTML}}`: If a `logo.svg` or `logo.png` file exists, it is embedded on the cover page; otherwise, a stylized typographic monogram is rendered.

## 4. Print & PDF Rules (@page and Paged Media)

To ensure clean printing:
1. **Dimensions**: A4 Portrait (`210mm x 297mm`).
2. **Safety margins**: `margin: 22mm 18mm 22mm 18mm` to allow running headers and footers.
3. **Automatic Pagination**:
   - `counter(page)` natively handled by browser paged media rules.
   - First page (cover) suppresses page numbering via `@page:first { margin: 0; }`.
4. **Page Break Protection**:
   - Critical elements (problem-solution boxes, milestone tables, summary cards) use `page-break-inside: avoid`.
   - Each major chapter starts on a new page via `page-break-before: always`.

---

## 5. Dual-Mode CSS Architecture (Screen Preview vs PDF Print)

A common mistake in report generation is relying solely on `@page` rules: web browsers ignore `@page` in screen mode, rendering text and tables edge-to-edge.

The generated CSS must always implement clean separation:

1. **For Print / PDF (`@page` and `@media print`)**:
   - Exact A4 sizing (`size: A4 portrait; margin: 20mm 18mm 20mm 18mm;`).
   - Exact backgrounds enabled (`print-color-adjust: exact; -webkit-print-color-adjust: exact;`).
   - No outer margin or padding on `body`.

2. **For Screen (`@media screen`)**:
   - `body`: contrast background (e.g. `#0b132b` or neutral slate), comfortable padding (`padding: 40px 20px;`).
   - `.cover-page` and `.chapter`: centered reader cards with controlled max-width (`max-width: 880px; margin: 0 auto 36px auto;`), soft drop shadow (`box-shadow`), rounded corners (`border-radius: 12px;`), and generous padding (`padding: 50px 48px;`).
   - `.cover-page`: fluid height (`height: auto; min-height: 860px;`) rather than fixed `100vh` to avoid clipping.
   - Responsive rules: `@media screen and (max-width: 768px)` ensuring readability across mobile and tablet viewports.
